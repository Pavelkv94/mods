# session-branches

Панель «Session branches» для Claude Code в терминале. Показывает дерево сессий
текущего проекта: какая сессия от какой ответвилась (`--fork-session`, `/branch`),
их названия (`/rename` или авто-заголовок) и сколько времени прошло с последней
активности. Текущая сессия помечена `●`.

Только для терминала: в десктопе, VS Code и на мобильном мод ничего не рисует
и не регистрирует команду. Панель открывается сама при старте сессии: колонкой
сбоку, если окно не уже 144 колонок (иначе — по `/branches`); на основном экране
терминала (без полноэкранного режима) — под перепиской.

## Как пользоваться

- `/branches` открывает панель и перечитывает список.
- Клик / Enter по строке открывает эту сессию в новой вкладке терминала
  (`claude --resume <id>`), текущая продолжает работать. Поддерживаются macOS
  Terminal (вкладка через System Events — нужен доступ Универсального доступа,
  без него откроется новое окно), iTerm2, tmux и WezTerm; в остальных команда
  копируется в буфер.
- `⇄` справа от строки переключает текущее окно на эту сессию (`/resume <id>`).
- `✕` удаляет сессию: после подтверждения («This one» или «With branches») её файлы
  переносятся в Корзину macOS, откуда их возвращает «Вернуть» в Finder. Текущую
  сессию окна удалить нельзя.
- `r` Refresh, `b` Fork current (если в вашей версии есть `/branch`).
- Esc возвращает фокус в поле ввода, панель остаётся.

## Подключение

```sh
claude --plugin-dir /path/to/session-branches
```

или постоянно, в `~/.zshrc`:

```sh
export CLAUDE_CODE_PLUGIN_DIRS=/path/to/session-branches
```

Родителя сессии мод определяет по скопированным в файл сессии сообщениям из
другой сессии (`~/.claude/projects/<проект>/*.jsonl`); смотрятся 60 последних сессий.
